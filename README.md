# DBMS
DBMS (Database Management System)

A Database Management System (DBMS) is software used to create, store, organize, retrieve, update, and manage data efficiently. It acts as an interface between users/applications and the database.

Definition

A DBMS is a software system that allows users to define, create, maintain, and control access to a database.

//Features
Stores large amounts of data
Reduces data redundancy (duplication)
Provides data security
Maintains data integrity
Supports multiple users
Enables backup and recovery
Provides fast data retrieval


//Components of DBMS
Database – Collection of related data.
DBMS Software – Manages the database.
Users – People who access the database.
Application Programs – Programs that interact with the DBMS.
Database Administrator (DBA) – Manages and maintains the database.


//Advantages
Reduces data redundancy
Improves data consistency
Provides better security
Enables data sharing
Supports backup and recovery
Easy data access and management


//Disadvantages
High installation and maintenance cost
Requires skilled personnel
Can be complex for small applications
Hardware requirements may be high
